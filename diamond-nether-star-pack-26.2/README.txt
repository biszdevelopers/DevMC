Diamond -> Nether Star custom texture pack (Minecraft Java 26.2)

Install:
1. Put diamond-nether-star-pack-26.2.zip in .minecraft/resourcepacks.
2. Enable the pack in Options > Resource Packs.

Test command:
/give @s minecraft:diamond[minecraft:custom_model_data={strings:['nether_star']}]

Only diamonds whose first CustomModelData string is "nether_star" use the custom
texture. Ordinary diamonds keep the normal diamond appearance.

This pack targets resource-pack format 88 used by Minecraft Java 26.2.
